# 17 clubs, everyone in a 2-count, and NOT ONE heff, hold or zip. Passes here are
# CROSS, right hand to right hand; star-17c-doubles-line.txt is the same pattern
# with every pass thrown line.
# Every self in this pattern is a plain 3. All the weight is in the passes.
#
#   A: double pass, self        starts with the pass     4 clubs
#   B: double pass, self        starts with the pass     3 clubs
#   C: self, double pass        starts with the self     3 clubs
#   D: self, double pass        starts with the self     3 clubs
#   E: SINGLE pass, self        starts with the pass     4 clubs
#
# A and B pass together on the even beats, from the right hand. C and D pass
# together on the odd beats, from the left hand. E passes with A and B, from the
# right, but throws a SINGLE where everyone else throws a double.
#
# It is exactly the 7-club two-person pattern you already know - one person
# opening with the pass, their partner opening with a self - wrapped round five
# people instead of two. Passing is across the star as usual:
#
#     A->C   B->D   C->E   D->A   E->B
#
#
# WHY SOMEBODY HAS TO THROW A SINGLE
#
# In this pattern everybody alternates hands in step, and while that holds a
# double pass leaves your right hand and lands in your partner's right, while a
# single lands in their left. (Offset someone's hands by a beat and it is the
# other way round - see star-17c-doubles-line.txt, which is this pattern with
# every pass turned into a line pass.) Either way a double flips which hand your
# partner passes from and a single does not. Follow the passing chain:
#
#     A -> C -> E -> B -> D -> A
#
# That chain closes on itself after five people. If every pass were a double,
# each one would flip the hand, and five flips would leave A passing from the
# opposite hand to the one it started on - a contradiction. You need an even
# number of doubles, and five is odd. Four doubles and one single is the closest
# you can get, and it is why this is 17 clubs and not 17.5.
#
# The single-pass job does not have to be E's. There are ten patterns like this
# one; any of the five can be the one throwing singles, and the rest shuffle to
# suit. Give it to whoever wants the easier throw.

name: 17c star doubles
beat: 0.33

jugglers:
  A at 0deg
  B at 72deg
  C at 144deg
  D at 216deg
  E at 288deg

start:
  A: R=2 L=2
  B: R=2 L=1
  C: R=2 L=1
  D: R=2 L=1
  E: R=2 L=2

loop:
  A: 4pC 3
  B: 4pD 3
  C: 3   4pE
  D: 3   4pA
  E: 3pB 3
