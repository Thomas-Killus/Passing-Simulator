# 17 clubs and EVERY ONE OF THE FIVE throws a double pass, all line, all from the
# right hand. E pays for the fifth double with a zip instead of a self.
#
#   A: double pass, self     4 clubs  2R 2L
#   B: double pass, self     4 clubs  2R 2L
#   C: self, double pass     3 clubs  1R 2L   starts on the LEFT hand
#   D: self, double pass     3 clubs  1R 2L   starts on the LEFT hand
#   E: double pass, ZIP      3 clubs  1R 2L   stands HALF A BEAT off the others
#
# Passing across the star as always:  A->C  B->D  C->E  D->A  E->B
#
#
# THE TRICK: E IS HALF A BEAT OFF THE BEAT
#
# With everyone on one beat grid, five double passes round a five-person star is
# impossible - the count of doubles has to be even (see star-17c-one-single.txt
# for why), so somebody always has to throw a single. Zips do not rescue that: a
# zip is a 1, odd like a 3, so swapping selfs for zips changes the club count but
# not the parity.
#
# What DOES rescue it is putting one person half a beat off. E throws between
# everyone else's beats. The two passes that touch E - C's pass to E, and E's
# pass to B - then have to hang in the air half a beat longer to land on the
# right hand at the right moment, which makes them 4.5 rather than 4. That is
# just the ordinary double pass of asynchronous passing; prechac writes it 4.5
# for exactly this reason. A 4.5 peaks about 40 cm higher than a 4 - floatier,
# same throw.
#
# So: five doubles, three of them a 4 and two of them a 4.5.
#
#
# WHERE THE ZIP COMES IN
#
# Five doubles carry a lot of clubs - with plain 3s everywhere this shape holds
# 18. E's zip takes one club back out and lands it on 17. Any of the five can be
# the one zipping; it is E here because E was the one throwing the single before.
# Two zips gets you 16, three gets 15, and so on down.
#
# E's zip is a handy moment: it is the one beat where a hand is free, which helps
# when you are half a beat out of step with everybody else.

name: 17c star one zip David
beat: 0.30

jugglers:
  A at 0deg
  B at 72deg
  C at 144deg start_hand L
  D at 216deg start_hand L
  E at 288deg phase 0.5

start:
  A: R=2 L=2
  B: R=2 L=2
  C: R=1 L=2
  D: R=1 L=2
  E: R=1 L=2

loop:
  A: 4pC line   3
  B: 4pD line   3
  C: 3   4.5pE line
  D: 3   4pA line
  E: 4.5pB line 1
